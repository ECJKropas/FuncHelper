# FuncHelper —— 随时随地构造函数（桌面悬浮球）

一个基于 `tkinter` 的小工具：在屏幕上放一个可拖动的悬浮球，通过点击三个点定义
**任意方向、任意比例的局部坐标系**，再点击若干数据点，最后自动拟合出一个
**穿过这些点的 n-1 次多项式函数** `y = f(x)`。

## 特性

- 悬浮球只有一个按钮，可拖动，可右键取消。
- 自定义坐标系：原点、`(1,0)`、`(0,1)` 三点连成的向量**不要求垂直、不要求等长**，
  程序内部用可逆仿射变换自动校正。
- 采集任意多个点，点击悬浮球结束，**从悬浮球右侧自动伸出一条横条显示函数字符串**
  （横条跟随球移动；左键点击复制、右键关闭）。同时把数据写入 JSON。
- **采集点时按住 Alt / Option 键**，局部坐标会自动吸附到最近的 `.5`
  （例如 `(2.4, 3.8) -> (2.5, 4.0)`），让表达式既干净又精确。
- 表达式使用 15 位有效数字输出，避免大坐标（屏幕像素级）被四舍五入后
  导致「公式字符串不再穿过标定点」的精度问题。
- **两种模式，空闲时右键悬浮球切换**（当前模式显示在顶部提示条）：
  - `多项式模式`：拟合穿过全部 n 个点的 n-1 次多项式 `y = f(x)`。
  - `折线段模式`：连续分段线性插值，表达式用 `abs` 写成闭合形式，
    例如 `y0 + m0*(x-x0) + Σ Δmi*((x-xi)+abs(x-xi))/2`，同样严格穿过各点。
- 纯 Python + tkinter + numpy，无外部权限要求（无需无障碍/辅助功能授权）。

## 安装与运行

```bash
# 在本目录创建虚拟环境（已用受管 Python 3.13 创建好 venv/）
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

```

## 使用步骤

1. 启动后，屏幕出现蓝点悬浮球 + 顶部提示条。
   （可选）**右键悬浮球**可在 `多项式模式 / 折线段模式` 间切换，当前模式见提示条。
2. **左键点击悬浮球「开始」** → 进入标定（出现几乎透明的全屏捕获层）。
   - 第 1 次点击：原点 `(0,0)`
   - 第 2 次点击：X 轴单位点 `(1,0)`
   - 第 3 次点击：Y 轴单位点 `(0,1)`
3. 进入采集模式，**每次左键点击记录一个数据点**（可采任意多个）。
   - **按住 Alt / Option 键点击**：该点局部坐标吸附到最近的 `.5`，表达式更整洁。
4. **左键点击悬浮球「结束」**：把所有点转到局部坐标系，拟合 `n-1` 次多项式，
   **从悬浮球右侧伸出横条显示函数字符串**（左键点击横条复制、右键关闭）。
5. 右键悬浮球 / 标定中途点球 = 取消并重置。

采集结束后会生成：
- `fit_result.json`：原始坐标、局部坐标、系数、函数表达式等完整数据
- 控制台同步打印函数表达式与系数

## 坐标系变换原理

三个屏幕点 `O, Px, Py` 给出局部基向量 `ex = Px - O`、`ey = Py - O`。
屏幕点 `S` 与局部坐标 `(a, b)` 满足：

```
S = O + a * ex + b * ey
```

解 2×2 线性方程组 `M [a, b]^T = (S - O)`，其中 `M = [[ex.x, ey.x], [ex.y, ey.y]]`：

```
a = (ey.y * dx - ey.x * dy) / det
b = (-ex.y * dx + ex.x * dy) / det
det = ex.x * ey.y - ey.x * ex.y
```

当 `det = 0`（三点共线）时报错，提示重新选择不共线的三个点。

## 多项式拟合原理

对局部坐标系下的 n 个点 `(xi, yi)`，构造 Vandermonde 方程组
`V c = y`，其中 `V[i][j] = xi^j`，求解升幂系数 `c`，
得到精确插值多项式 `p(x) = c0 + c1 x + ... + c_{n-1} x^{n-1}`（即 n-1 次）。

注意：要求所有 `xi` 互不相同，否则无法表示为单值函数 `y = f(x)`。
